# Cinnarios prototype v1 (archived 17 November 2026)

Snapshot of the stand-alone AR decision-support prototype submitted with the capstone report on 16 November 2026, kept before the project moved to a full online art shop with AR try-on.

## What it contains
- `Assets/`, `Packages/`, `ProjectSettings/`: the complete Unity 6000.5.0f1 project (AR Foundation 6.5.0, ARKit, iPhone 13).
- Domain assemblies: Capstone.Catalogue, Dialogue, Ranking, Session, Placement, each with EditMode tests (204 cases).

## How to open it
Copy this folder somewhere outside the repo and open it with Unity Hub (Unity 6000.5.0f1). The `Library/` folder is not stored, so the first import takes a few minutes.

Frozen. Do not edit; new work happens in the new project.
